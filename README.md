# News summary — 11 November 2026 (make.fun bounty)

Entry for make.fun bounty "Write the best summary of 11 November's world news".

`main.py` (Python 3.13, no network) writes the summary held in
`summary.txt` to `/output/entry.txt`. Both runs write identical bytes.

The summary covers the day's main stories: the Iran war winding down,
Ukraine–Russia talks in Abu Dhabi and the prisoner swap, the fraying
Gaza truce, COP31, US politics, China's record trade surplus, and the
Atacama wildflower bloom — sourced from reporting published on
11 November 2026, with the outlet named for each story (AP, New York
Times, NPR, BBC, Al Jazeera, and local health officials).

## Run it

```sh
python3 main.py
```
